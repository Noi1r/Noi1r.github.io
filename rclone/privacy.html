rclone · Personal ePrint backup

Privacy policy

Effective September 9, 2026

This policy covers Lizheng Wang’s personal rclone configuration for backing up a research paper archive to Google Drive.

Data accessed and purpose

Google OAuth provides access and refresh tokens that allow the program to act on the authorized Drive account. The granted scope permits reading, creating, modifying, and deleting Drive files. The configured backup uses Drive folder and file metadata, such as names, sizes, modification times, and hashes, to locate the destination and compare files. Paper files are sent from the server to Google Drive when they need to be uploaded or updated.

Account information returned during authorization or connection checks may be used to identify the authorized account. This information and the Drive data are used only to configure and operate the owner’s backup.

Storage and protection

Authorization credentials are stored in the server’s rclone configuration with access restricted to its user account and system administrators. A temporary copy may be used on the owner’s computer during initial authorization and removed after setup. Transfer logs on the server may contain file paths, transfer statistics, and error messages. Credentials are not published on this website or intentionally written into transfer logs.

Source papers remain on the server; uploaded copies are stored in the owner’s Google Drive. Backup file transfers occur directly between the server and Google over encrypted connections.

Sharing and limited use

Google receives the files and metadata needed to provide Drive storage. The rclone project does not receive the owner’s authorization tokens or file contents through this configuration. The operator does not sell Google user data, use it for advertising, or use it to train general-purpose AI models.

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and revocation

Credentials are retained while the backup is in use and can be removed from the server configuration. Access can be revoked through Google Account connections. Revoking access stops future authorized transfers; it does not delete files already stored on the server or in Drive. The owner controls deletion of those files and the local transfer logs.

This website and contact

These informational pages contain no application sign-in form, file-upload form, or analytics script. The website’s hosting and delivery providers, GitHub Pages and Cloudflare, may process normal web-request information to deliver the pages. This is separate from Google Drive authorization and backup transfers.

The operator is Lizheng Wang. Contact details are available on the personal website. Changes to this configuration’s data practices will be reflected in this policy.

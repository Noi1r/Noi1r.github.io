rclone

Personal ePrint backup

This is Lizheng Wang’s personal configuration of the open-source rclone file-transfer program. It copies a research paper archive from a server to the owner’s Google Drive and runs daily to upload new or updated files.

Google Drive access

The application requests permission to view, modify, create, and delete Google Drive files. This permission supports finding the backup folder, comparing existing files, and uploading the archive. The configured daily backup uses copy operations: removing a source file does not remove its backup from Drive.

Authorization is granted directly through Google. The saved authorization lets the server run scheduled transfers without an interactive login each day. The owner can revoke access at any time in Google Account connections.

Personal use

This configuration is for the owner’s use. It is not a public backup service and does not accept sign-ups or uploads from visitors. This page describes a personal deployment, not the rclone project or an official IACR service.
